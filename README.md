# DYHTG
Code for DYHTG? Hackathon

## Team Members
## Sam, May, Olivia, Elodie
We have created a two input game where the player is tasked with making a robot out of scraps found in a dump yard. The player needs to collect four parts: the legs, the body, the arms and the head. For each part the player will be offered a random part type that they can either accept or reject, however, if the player doesn’t accept the first 2 offers they will be forced to accept the next one.
